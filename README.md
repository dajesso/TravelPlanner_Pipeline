I started off creating a few files, one for deployment, one for testing and one for seeding the database. I had to configure the scripts to set up the node environment, secret variables. Dependences and tests. To run the scripts all you must do is open the actions tab and run the needed scripts and it does everything for you. I have a app.yml script which executes the index.js script from the project it setups up the repo which branch it is being deployed from and sets the environments such as JWT_SECRET, MONGO_URL for deployment I use a deploy script it just contains the information for the deployment of the application and the secrets stored in github as environment variables. The nodeJS.yml file is where all the important setup happens it creates an image of the latest version of ubuntu sets up mongo and defines the port it uses it then runs the actions and installs anything needed. Lastly, I have a seed.yml script is simple install what is needed then runs the script.


In an application that uses CI/CD each service and technology have its own roles and relies on them to function properly. CI is used to run tests and deploy and host the final product.
